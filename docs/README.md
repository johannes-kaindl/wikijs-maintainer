# Wiki.js Maintainer — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning something and fixing something are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first published page.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Connect a Wiki.js, move a note into the sync folder, push it. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "The wiki rejected the API key", "Blocked: … changed on the wiki", "Occupied", "Slug collision". |

The [README](https://github.com/johannes-kaindl/wikijs-maintainer/blob/main/README.md) covers what the plugin does, every setting, how the drift guard works and the limits of this version.

---

`SMOKE.md`, `LAB.md`, `OPEN-POINTS.md` and `superpowers/` hold maintainer material (the test checklist, the GraphQL schema as measured, deferred findings) and are not user documentation.
